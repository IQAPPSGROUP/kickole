# Bundled footballer

The game loads `kickole_player_v4.glb` (male) or `kickole_player_v4_female.glb`
by default, with the matching `*_lod1.glb` on the low tier. Those four files
are optimised Fab Standard licence characters. See `LICENSE` for the terms
and `docs/CHARACTER_GLB.md` for the rig. `kickole_player_v3.glb` is the older
stylised build from the Quaternius CC0 source `kickole_player_v2.glb`
(`tools/build_player_v3.ts`). See `LICENSE.txt` for the CC0 terms. Set
`VITE_USE_GLB_CHARACTER=false` to use the primitive fallback.

`kicky-player-rigged.glb` is the older procedural reference, generated by
`tools/generate_kicky_player.py`. That generator builds geometry, materials,
bones and keyframes in Blender and does not import third-party models. Its
MIT terms are also in `LICENSE.txt`.

The `_L` and `_R` suffixes follow control/world-X sides, not anatomical sides.
See `docs/CHARACTER_GLB.md` for the rig, contact and export contract.
