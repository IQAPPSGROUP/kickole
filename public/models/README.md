# Bundled footballer

The game loads `kickole_player_v3.glb` by default. It is built from the
Quaternius CC0 source `kickole_player_v2.glb` by `tools/build_player_v3.ts`:
contract bone names, dropped finger bones, eyes folded into the skin atlas,
and the five clips Idle, KickLeft, KickRight, Miss and Celebrate. See
`LICENSE.txt` for the CC0 terms. Set `VITE_USE_GLB_CHARACTER=false` to use
the primitive fallback.

`kicky-player-rigged.glb` is the older procedural reference, generated by
`tools/generate_kicky_player.py`. That generator builds geometry, materials,
bones and keyframes in Blender and does not import third-party models. Its
MIT terms are also in `LICENSE.txt`.

The `_L` and `_R` suffixes follow control/world-X sides, not anatomical sides.
See `docs/CHARACTER_GLB.md` for the rig, contact and export contract.
