# Bundled footballer

The game loads `kickole_player_v4.glb` (male) or `kickole_player_v4_female.glb`
by default, with the matching `*_lod1.glb` on the low tier. Those four files
are optimised Fab Standard licence characters. See `LICENSE` for the terms
and `docs/CHARACTER_GLB.md` for the rig. Set
`VITE_USE_GLB_CHARACTER=false` to use the primitive fallback.

The `_L` and `_R` suffixes follow control/world-X sides, not anatomical sides.
See `docs/CHARACTER_GLB.md` for the rig, contact and export contract.
