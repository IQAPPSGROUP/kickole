# Bundled footballer

## Default: `kickole_player_v2.glb` (Freddie / Quaternius CC0)

Modelled kit + boots, UE mannequin bone names, Meshopt + WebP. Loaded by default via
`CHARACTER_MODEL_URL`. See `docs/FREDDIE_CHARACTER_MODELS.md`. Rebuild tools live under `tools/freddie/`.

No authored clips yet — the loader maps UE bones (with L/R swap) and drives procedural pose.

Override: `VITE_CHARACTER_MODEL=models/kicky-player-rigged.glb`  
Disable GLB: `VITE_USE_GLB_CHARACTER=false`

Also present: `kickole_player_v1.glb` (earlier kit-as-skin-split variant).

## Legacy: `kicky-player-rigged.glb`

Generated by `tools/generate_kicky_player.py`. Full Mixamo-style contract bones plus the five clips
(Idle, KickLeft, KickRight, Miss, Celebrate). See `LICENSE.txt` for MIT terms on this asset;
Quaternius Freddie assets are CC0 (same file).

The `_L` and `_R` suffixes follow control/world-X sides, not anatomical sides.
See `docs/CHARACTER_GLB.md` for the rig, contact and export contract.
